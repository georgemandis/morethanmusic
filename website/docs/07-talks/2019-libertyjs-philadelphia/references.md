# Resources & Documentation

[MDN WebMIDI Reference](https://developer.mozilla.org/en-US/docs/Web/API/MIDIAccess)  
A decent overview of the WebMIDI implementation

[Circuit Playground Library Reference](https://learn.adafruit.com/circuit-playground-lesson-number-0/circuit-playground-library)  
Documentation for the various sensors and capabilities of the Circuit Playground Express

[Arduino Reference](https://www.arduino.cc/reference/en)  
If you've never worked with  Arduino hardware before (or even if you have!) it's helpful to have the reference on hand

[W3C Web MIDI API](https://www.w3.org/TR/webmidi/)  
Proposal for the Web MIDI API

[Getting Started with the Web MIDI API](https://www.smashingmagazine.com/2018/03/web-midi-api/)  
Good article from Smashing Magazine giving an introductory overview

[Web Audio Demos](http://webaudiodemos.appspot.com/)  
A good number of these utilize Web MIDI and are great examples of musical applications


[WebMidi.js](https://github.com/djipco/webmidi)  
Although the WebMIDI API is pretty straightforward to begin with, if you're going to work with preexisting MIDI controllers or have a more conventional MIDI project in mind this library makes working with the API even simpler

[MIDIUtils](https://github.com/sole/MIDIUtils)  
If you need to translate MIDI messages to musical notes and pitches for your project this collection of methods is extremely helpful
