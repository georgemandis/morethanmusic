# Workshop Agenda

## What We're Building

In this workshop we will be learning about MIDI, how to build our own simple MIDI controllers and how these custom-built MIDI controllers can interface with web pages using the [WebMIDI API](https://www.w3.org/TR/webmidi/) and JavaScript. 

We'll discover very quickly that this simple protocol designed for electronic musical instruments can be used in fun, interactive and completely non-musical ways!

## Things We'll Need

For this workshop we'll need:

- <strong>A [Circuit Playground](https://www.adafruit.com/product/3333) SBMC, which has been provided to you!</strong> There are *many* single-board microcontrollers and computers out there you can fashion into MIDI hardware. The Circuit Playground was chosen for this workshop as it has [many fun sensors](https://learn.adafruit.com/adafruit-circuit-playground-express/guided-tour) already built-in, making it great for experimenting.

- <strong>A WebMIDI-capable browser such as [Chrome](https://www.google.com/chrome), [Chromium](https://www.chromium.org/getting-involved/download-chromium) or [Opera](https://www.opera.com/)</strong>. Currently these are the only browsers will full support for WebMIDI, though it's in the pipeline for Firefox.

Nice to have but not strictly necessary:

- <strong>An account with <a href='http://glitch.com/'>Glitch</a>, <a href='https://codepen.io/'>CodePen</a> and <a href='https://github.com'>GitHub</a></strong>. If you'd like to save your projects it would be best to have an account with one or all three of these services.


## What We'll Do

1. Briefly review how MIDI, MIDI Controllers and MIDI messages work
1. Overview how our CircuitPlaygrounds are setup as MIDI controllers
2. Build a "Hello World" WebMIDI app together, reading and sending MIDI messages
3. Explore example projects together
4. Guided time for participants to start building a WebMIDI project of their choosing. Ideas will be provided but participants are encouraged to explore their own!
5. Discuss possibilities for further exploration and projects to hack away on together
6. Review and discuss where to go from here
