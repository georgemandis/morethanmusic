# Let's Build Things!

For the browser-side components of any of these projects you can start by looking at this starter code on CodePen:

- [https://codepen.io/georgemandis/pen/erKKNN](https://codepen.io/georgemandis/pen/erKKNN)

You can also look at lots of examples via links in the [resources & documentation](./references.md) section.

## Basic Synthesizer

For this project we'll build a basic synthesizer using WebMIDI, a web-based interface and the onboard speaker in our Circuit Playground.

## Color Mixer

We'll manipulate the built-in Neopixels in our Circuity Playground to mix colors using a web interface.

## Quiz Buzzer

Let's make our Circuit Playground create a sound and flash a particular color when a user answers a questions correctly or incorrectly in a quiz.


## Morse Code Translator

Let's translate phrases to morse code using the onboard speaker in our Circuit Playground.

## Fruit Piano

Using alligator clips and fruit (or any conductive material!) we'll build an "alterantive" piano.

## Real-world Flash Cards

Using principles from the previous project we'll explroe a non-musical application for this same setup.
