## What happened

The SPA site with a new title, "JavaScript + MIDI + Microcontrollers Workshop", and Microsoft Edge
added to Chrome, Chromium and Opera. Firefox was still "in the pipeline". The ten modes, the
project list and the CodePen starters are the 2018 pages with the typos fixed.

It was deployed to the same GitHub Pages address as the SPA site. Both are offline now, and neither
was captured by the Wayback Machine.
