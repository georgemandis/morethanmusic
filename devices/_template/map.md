## What it sends

| Control | Message | Numbers | Notes |
|---|---|---|---|
| Pad 1 | Note on, note off | 36, velocity 127 | Channel 1. |
| Knob | CC | CC 1, 0 to 127 | 0 at the left. |
| USB name | | "Device name" | The Explorer prints the exact name. |

## What it receives

| Message | Effect |
|---|---|
| Note on 36, velocity above 0 | Lights pad 1. |
| none | Delete this section if the device has no lights. |
