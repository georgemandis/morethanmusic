# References

Documentation for everything used on this site. One line each on why you would open it.

## Documentation

[javax.sound.midi (Java 17)](https://docs.oracle.com/en/java/javase/17/docs/api/java.desktop/javax/sound/midi/package-summary.html)
The MIDI package inside every Processing. `MidiSystem`, `ShortMessage` and `Receiver` are the three
classes the helpers are built from.

[Processing reference](https://processing.org/reference)
Everything else in the sketches.

[Python Mode for Processing](https://py.processing.org/reference/)
The same, for Python Mode.

[Summary of MIDI 1.0 Messages (MIDI Association)](https://midi.org/summary-of-midi-1-0-messages)
Every status byte on one page. The [MIDI 1.0 specification](https://midi.org/midi-1-0-core-specifications)
is the long version.

[Dip Your Toes Into Hardware With WebMIDI (CSS-Tricks)](https://css-tricks.com/dip-your-toes-into-hardware-with-webmidi/)
George's write-up of Web MIDI from the first `requestMIDIAccess` call.

[useMidi](https://usemidi.com)
Masson's PipSqueaks and the [configurator](https://usemidi.com/configure.html) that sets what they send.

[Web MIDI API (W3C)](https://www.w3.org/TR/webmidi/) and
[MDN: MIDIAccess](https://developer.mozilla.org/en-US/docs/Web/API/MIDIAccess)
What the p5 sketches use.

[Launchpad Mini MK3 Programmer's Reference](https://fael-downloads-prod.focusrite.com/customer/prod/s3fs-public/downloads/Launchpad%20Mini%20-%20Programmers%20Reference%20Manual.pdf)
Pad numbering, the palette, the SysEx commands for RGB and text.

[Midi Fighter Classic firmware](https://github.com/DJ-TechTools/Midi_Fighter_Classic)
What the device does with an incoming note.

[Circuit Playground MIDI multi-tool](https://github.com/georgemandis/circuit-playground-midi-multi-tool)
George's firmware for the Circuit Playgrounds. Flash it from the Arduino IDE to change what a mode
sends.

[CircuitPython usb_midi](https://docs.circuitpython.org/en/latest/shared-bindings/usb_midi/)
How the Trinkeys became MIDI devices in forty lines.

[Adafruit Circuit Playground library](https://learn.adafruit.com/circuit-playground-lesson-number-0/circuit-playground-library)
The sensors and what they return.

[Processing Community Day](https://processingfoundation.org/)
The people who made the 2026 workshop happen.
