# Workshop Agenda

## What We're Building

In this workshop we will be learning about MIDI, how to build our own simple MIDI controllers and how our custom-built MIDI controllers can interface with simple web pages using WebMIDI and JavaScript. We'll discover very quickly that this simple protocol designed for electronic musical instruments can be used in fun, interactive, non-musical ways!

## Things We'll Need

For this workshop we'll need:

- A [Circuit Playground Express](https://www.adafruit.com/product/3333). These have been provided courtesy of Adafruit! There are *many* microcontrollers out there you can turn into MIDI controllers, but this one has a lot of fun sensors already built-in, making it great for experimenting.
- The [Arduino IDE software](https://www.arduino.cc/en/Main/Software). This is the software we will use to upload code to our Circuit Playground's and turn them into MIDI controllers.
- The [Chrome](https://www.google.com/chrome) or [Chromium](https://www.chromium.org/getting-involved/download-chromium) web browser. Currently these are the only browsers will full support for WebMIDI, though it's in the pipeline for Firefox.


Before getting started make sure you've downloaded and installed the softare mentioned above!
