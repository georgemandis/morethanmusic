# Examples

Everything runnable, grouped by what it teaches rather than by which workshop it was built for. The
p5.js versions run on this page or the device pages. The Processing versions are in the repo, one
folder per sketch, with the helper tabs already inside.

## First contact

- [Hello world](./hello-world.md). The PipSqueak starter, under forty lines, walked through line by
  line in all three languages.
- [The three bytes, no helpers](./three-bytes-no-helpers.md). The same idea with no helper at all,
  so you see the raw bytes arrive.

## One starter per device

Each [device page](/devices/) has its starter in p5.js, Python Mode and Java, and a raw version under
sixty lines that decodes its own messages. In the repo: `starters/<language>/` and `starters/raw/`.
From a browser, `/starters/p5/<device>/` runs the p5 one.

## Ports of the old demos

The Launchpad cellular automata and the Midi Fighter sequencer from the 2017 talks, ported to
Processing and p5. Embedded on the [Demos](./demos.md#ports-you-can-take-apart) page, source in
`ports/`.

## The PipSqueak projects

Ten small projects, each under about sixty lines, in all three languages: cursor, compass,
etch-a-sketch, knob, timer, bouncy ball, snake, maze, obstacle course, flock. The p5 versions run from
the [Demos](./demos.md#pipsqueak-projects-built) page. Source in `projects/`.
